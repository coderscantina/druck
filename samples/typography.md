Offer for the 2026 report {.eyebrow}

# What we propose

The annual report runs to about 120 pages of text, tables, and figures, and it appears in English and German. We set both editions from the same Markdown sources with one theme, so a correction made once reaches every page that shows it. This offer lists what is included, how the work proceeds, and how the weights of the type are chosen.

Each heading in this offer has a short label above it, set in small spaced capitals. The label is a paragraph in a custom style that keeps it with the next block, so a page never ends between a label and its heading.

How the work proceeds {.eyebrow}

# Steps

The work runs in three steps. Each step heading starts with the number typed by the author, which hangs in front of the text, so the lines of a long heading start at the same place.

### 1. Collect the material {.step}

We collect the text, the tables, and the figures for every chapter, together with the corporate colors and the logo.

### 2. Agree on the design, the type sizes, and the spacing that every chapter of the report will use {.step}

A sample chapter shows the design. Changes to it go into the theme, so the remaining chapters follow without further work.

### 3. Deliver the final files {.step}

After two rounds of corrections we deliver the files and the sources that produced them.

Choosing the weights {.eyebrow}

# Light and medium type

A style may ask for any weight from 100 to 900, and the font family maps each weight to a face. The bundled Libertinus Serif has a regular and a bold weight only, so this theme lists those two files again as weight 300 and weight 500. With an installed family such as Avenir Next, the same styles would get its real light and medium faces.
