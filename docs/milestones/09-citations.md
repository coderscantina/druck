# 09: Citations and bibliography

## Goal and prerequisites

Complete scholarly references without adding math or arbitrary CSL support. Requires milestone 08.

Read citations/bibliography, resources, document structures, and diagnostics in [the briefing](../BRIEFING.md).

## Deliverables

- External local BibTeX input and supported article, book, conference, thesis, report, and web entries.
- Built-in author-date and numeric styles with multiple keys, page locators, and narrative citations.
- Documented required fields and concrete formatting rules.
- Bibliography composition using theme styles and the shared layout pipeline.
- Errors for missing keys/required fields; ignored unknown optional fields.

## Completion criteria

Render both styles using every supported entry type. Include grouped and narrative citations with locators, bibliography entries that wrap, and references adjacent to column/page boundaries. Verify expected citation ordering and formatting against the documented rules.

Inspect complete English and German reports and repeat the milestone 08 integration scenario with bibliography content. Verify stable page references, preserved content, local resource origins, and focused error cases. Broader BibTeX semantics remain outside the release contract.
